# Alan De Vaney

Software engineer in Orange County, CA. I build data systems and AI-enabled tools for evidence-based decisions.

For five years I ran the data platform at an Orange County homeless-services agency. I cut funder reports from two to three days of manual assembly to on demand. I built an interactive report where each figure opens the records behind it, and program directors used it to fix their own data. I also wrote an independent Python implementation of the HUD Annual Performance Report that matches the vendor's report exactly, and we used it to verify the agency's own reports. Those repositories are private, because the data underneath them concerns real people in crisis.

Since 2017 I have been building a C++ trading system on my own time. The current C++23 engine replays four hours of live exchange data in 15 seconds and decides on market data in about a microsecond. It is tested under address, thread and undefined-behavior sanitizers.
