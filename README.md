# Alan De Vaney

Software engineer in Orange County, CA. I build data pipelines and applied AI for teams that have to trust their numbers.

For five years I ran the data platform for a 16-program homeless-services agency. I cut funder reports from two to three days of manual assembly to on demand. I also wrote an independent Python implementation of the HUD Annual Performance Report that matches the vendor's report exactly, and we used it to verify the agency's own reports. Those repositories are private, because the data underneath them concerns real people in crisis.

Since 2017 I have been building a C++ trading system on my own time. The current C++23 engine replays four hours of live exchange data in 15 seconds and decides on market data in about a microsecond. It is tested under address, thread and undefined-behavior sanitizers.
